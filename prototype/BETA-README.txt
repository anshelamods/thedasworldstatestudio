THEDAS WORLD STATE STUDIO - 1.0.4
Windows x64 - 23 October 2026

Create an Origins and Dragon Age II World State, then export it as an FBMOD
for Dragon Age: Inquisition. The editor works offline with local artwork.
Python and Frosty Editor do not need to be installed.

GETTING STARTED
1. Extract the whole ZIP to a normal folder. Keep _internal beside the EXE.
2. Run Thedas World State Studio.exe. It opens an Edge app window, or your
   default browser.
3. Create a World State from a preset, or use Import Save to choose a PC DAO
   or DA2 .das save. New histories use Original game defaults with DAO and DA2
   marked as played. The two Queen Cousland / Rogue Hawke presets are optional.
4. Choose your answers and save. Export as FBMod lets you choose a title,
   filename and destination folder. FBMOD settings controls author, description
   and the optional custom icon.
5. Install and enable the exported .fbmod in Frosty Mod Manager. Launch using
   your normal mod setup and start a NEW game using DEFAULT WORLD STATE.
   Existing Inquisition saves are not changed. Keep login is not required.

Use one world-state replacement mod at a time. Other mods replacing
DA3/Configurations/Online/BWWorldStateConfigAsset conflict with this export.

SAVE IMPORTS AND CHOICES
DAO and DA2 saves can create a new World State or update an existing one.
Only fill missing choices protects imported and manually chosen answers,
including answers that match the defaults. Replace recovered choices updates
only outcomes recovered from the incoming save. A DA2 save can also supply
retained Origins history; missing information keeps existing answers/defaults.
Original game saves are read only and are not copied into the package.

Some outcomes are missing, conflicting or no longer recorded in game saves.
Choose those manually. Review remaining choices after import opens a combined
DAO/DA2 list of choices still needing selection. Back to tapestry restores
normal game-specific navigation.

Options includes the quick editor, search/filters, import review, diagnostic
data and No Story Restrictions. With normal restrictions, conflicting choices
show related changes for confirmation. Modded imports enable No Story
Restrictions automatically when needed to preserve recovered choices.
Some captured Keep choices have no confirmed Inquisition effect; eleven are
stored in the World State only. Diagnostic data identifies those choices.

WORLD STATES AND UPGRADES
World States, revisions, settings and logs are stored in:
%LOCALAPPDATA%\ThedasWorldstateStudio

Extract upgrades into a new folder; saved World States and settings stay in
the same location. This update gives saved folders readable names and adds
a current World State JSON, preserving existing choices and saved revisions.
Open World State folder in the navigation drawer opens this location.
To apply an
import correction to an explicit answer, change it manually or reimport using
Replace recovered choices.

Manage World States provides creation, duplication, opening, saved revisions,
World State JSON import/export and deletion. Export World State JSON for a
portable backup; an FBMOD or its report is not an editable history backup.
Deleted histories can be restored until Delete permanently or Empty deleted
World States removes their saved revisions. Separate exports/backups are kept.

Changed saves keep the latest 20 saved versions, including the current version,
in History. Existing older history is kept during migration until the next
changed save. Saved revisions includes Clear saved revisions, which keeps the
current saved World State and unsaved edits. Use Export World State JSON for
independent backups outside app storage. If comparing an older app version,
use a separate data-folder copy; older builds cannot read the new layout.

Save before closing. The app normally exits a few seconds after its last
window closes, once active operations finish.
